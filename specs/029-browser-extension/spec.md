# Feature Specification: 029-browser-extension (Desh Browser Extension)

**Feature Branch**: `029-browser-extension`  
**Status**: Planned  

---

## 1. Overview

Users, freelancers, and businesses in Bangladesh frequently check daily exchange rates, BAJUS gold prices, upcoming prayer times, or need to verify a postal code while working in their browser.

The Desh Browser Extension (Manifest V3 for Google Chrome, Mozilla Firefox, and Microsoft Edge) provides a quick-access toolbar popup with live Bangladesh essentials.

---

## 2. Features

- **Prayer Countdown**: Current waqt badge with countdown timer to the next prayer (customizable for all 64 districts).
- **Gold & Commodity Prices**: Today's 22K/21K/18K gold rate per vori/gram and official TCB retail food prices.
- **Quick Postal & Area Lookup**: Search post codes and upazila boundaries directly.
- **Bangla Tools Quick Access**: Quick number-to-words, Bijoy-to-Unicode conversion, and date converter.
