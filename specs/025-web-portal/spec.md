# Feature Specification: 025-web-portal (Consumer Web Portal & Playground)

**Feature Branch**: `025-web-portal`  
**Status**: Built & Live (`portal.deshapi.riadul.com`)  
**Directory**: `web/`

---

## 1. Overview

Desh API requires a modern, responsive consumer web portal and developer playground accessible directly via browser. The portal demonstrates the full power of the platform to non-developers, product managers, and developers through interactive visual widgets and real-time live API query inspectors.

---

## 2. Implemented Features

1. **Interactive Widget Suite**:
   - Administrative Area Explorer (Divisions, Districts, Upazilas, Postcodes).
   - Live Prayer Times & Ramadan Sehri/Iftar countdown with 64 district offsets.
   - Live BAJUS Gold Rate converter and Zakat calculator.
   - Live TCB Daily Commodity market prices and BPC fuel prices.
   - Metro Rail (MRT Line-6) fare calculator and station directory.
   - Income Tax (Finance Act 2026) and EMI / Gratuity calculators.
   - Bangladesh Railway intercity train search and coach classes.
   - Emergency & Healthcare hotline and hospital locator.
   - Heritage & Tourism exploration map and BLPA land port inspector.
2. **Interactive Developer Playground & Inspector**:
   - Live URL preview, curl generator, response JSON syntax highlighting.
   - Dynamic query parameter builder.
   - One-click copy for curl, JavaScript fetch, and Python snippets.
3. **Responsive UI**:
   - Modern Tailwind CSS styling, dark/light theme, bilingual toggle.
